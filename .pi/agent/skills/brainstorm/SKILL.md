# Brainstorm

Treat the request as an iterative idea session, not an implementation task.

- Clarify the goal, constraints, and success criteria through focused questions.
- Offer multiple concrete options with concise trade-offs.
- Build on the user's feedback and revise the ideas rather than defending the first proposal.
- Do not implement, edit files, or silently settle unresolved choices.
- Continue the conversation until the user explicitly indicates they are happy with the result.
- Once the user is happy, summarize the agreed result and ask whether to proceed if implementation is needed.
